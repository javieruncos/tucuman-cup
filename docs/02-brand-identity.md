# Brand Identity

> **Proyecto:** Tucumán Cup
> **Versión:** 1.0
> **Estado:** Activo
> **Última actualización:** Agosto 2026

---

# 1. Identidad de Marca

Tucumán Cup es una plataforma moderna para la gestión de torneos de fútbol amateur.

La identidad visual debe transmitir:

* Profesionalismo
* Competencia
* Energía
* Confianza
* Organización
* Pasión por el fútbol

El producto debe sentirse como una mezcla entre:

* La claridad de Sofascore.
* La modernidad de Linear.
* La elegancia de Vercel.
* La energía visual de EA Sports FC.

Sin copiar ningún diseño existente.

---

# 2. Personalidad Visual

Si Tucumán Cup fuera una marca, sería:

* Moderna
* Premium
* Deportiva
* Confiable
* Dinámica
* Minimalista
* Profesional

Evitar:

* Interfaces recargadas.
* Colores excesivos.
* Gradientes agresivos.
* Efectos innecesarios.
* Estilo genérico de SaaS.

# 10. Estilo de Componentes

Los componentes deben ser:

* Limpios.
* Reutilizables.
* Legibles.
* Rápidos de entender.

Cada componente debe tener:

* Hover
* Focus
* Disabled
* Loading
* Empty State

---

# 11. Estilo de Tarjetas

Las cards son un elemento central.

Deben tener:

* Fondo oscuro
* Bordes sutiles
* Buen espaciado
* Jerarquía clara

Ejemplo:

* TournamentCard
* TeamCard
* MatchCard
* PlayerCard

---

# 12. Tablas

Las tablas deben ser:

* Fáciles de leer.
* Compactas.
* Responsive.

No parecer hojas de cálculo.

---

# 13. Animaciones

Duraciones:

```text
150ms
200ms
250ms
```

Permitir:

* Hover
* Fade
* Slide
* Scale suave

Evitar:

* Animaciones largas.
* Efectos exagerados.

---

# 14. Responsive

Diseñar primero para:

```text
Desktop
```

Adaptar luego a:

```text
Tablet
Mobile
```

---

# 15. Dark Mode

El modo oscuro es el modo principal.

No invertir colores automáticamente.

Diseñar específicamente para dark mode.

---

# 16. Sensación General

La aplicación debe sentirse:

* Profesional
* Premium
* Deportiva
* Moderna
* Rápida
* Clara

El usuario debe percibir que está utilizando una plataforma especializada en fútbol y no un dashboard genérico.

---

# 17. Regla Principal

Cada elemento visual debe responder a una pregunta:

> ¿Esto ayuda al usuario a entender mejor la información o a tomar una decisión más rápido?

Si la respuesta es no, el elemento no debe existir.
